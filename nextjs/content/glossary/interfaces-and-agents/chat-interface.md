# Chat interface

**The screen that organizes an exchange as messages between a user and an assistant.**

## In plain terms

A text box, a send button, and alternating messages give the model a conversational setting. In our running example, the Course TF Assistant can look like a tutor before we inspect any of its instructions.

Compare the interface with the text supplied to the model: a visible bubble and an underlying message are different things to inspect. This is the distinction the persona dial asks us to test.

## In the readings

Sacks, Schegloff, and Jefferson, [§1, observations 1–4](https://github.com/ll-26-27/eng-298ai-context/blob/24df8b8/_context/course-readings/course-readings-md/sacks-schegloff-jefferson-1974-turn-taking.md), describe speaker changes, overlap, and gaps in ordinary conversation. Comparing that organization with a send button and alternating bubbles is a course connection, not their account of chat software.
