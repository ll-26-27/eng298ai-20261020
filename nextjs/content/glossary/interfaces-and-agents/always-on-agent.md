# Always-on agent

**An agent service designed to remain available and respond to triggers beyond one chat session.**

## In plain terms

Here the term describes an operating arrangement: a timer, message, or other event can initiate a run. It does not mean the model must be generating continuously.

The course’s history collection includes announcement-page screenshots presenting persistent agents. Their feature and availability claims need independent confirmation (verify). For a hypothetical Course TF Assistant, distinguish “respond when a student messages” from “check the course site every morning.”
