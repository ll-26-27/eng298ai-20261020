# An agent’s own computer

**A dedicated computing environment in which an agent can keep files and run its tools.**

## In plain terms

The layers brief distinguishes agency on a user’s machine from agency with a separate computer. This is a deployment distinction: ask where the files, browser session, and execution process live.

Imagine moving the Course TF Assistant from a student’s laptop to a dedicated remote machine. The location changes, but questions about credentials, permissions, persistence, and review remain. A separate machine and a sandbox are different kinds of boundary.
