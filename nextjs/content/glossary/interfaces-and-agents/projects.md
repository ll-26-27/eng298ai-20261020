# Projects

**Containers that group related conversations, reference material, and instructions.**

## In plain terms

A project supplies a working setting for repeated conversations. In ChatGPT, project instructions apply within the project. Do not assume every product uses the same sharing or memory rules.

For the Course TF Assistant, the useful question is: what is carried into a new conversation because it belongs to this project?
